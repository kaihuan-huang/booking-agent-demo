Booking Agent Demo

A bilingual (English / 中文) restaurant booking agent that never books until the guest says yes, and never fills in a value the guest didn't give.

Kaihuan HuangIndependent reimplementation · all data is synthetic

Try it

Rules, not a model, read the date, time, party size and name. Anything unclear becomes a question. The only action, create_reservation, runs after an explicit yes.

Compare with an LLM on your machine

The first version let a language model read the booking details. Measured, it filled in values the guest never gave, so the model came out of the booking path. If you run Ollama, this page can ask your local model to read the same conversation and show where it would have guessed. Nothing leaves your computer.

# once, then restart Ollama
ollama pull qwen2.5:7b
OLLAMA_ORIGINS="https://kaihuan-huang.github.io" ollama serve

Chrome may ask to let this page reach your local network; allow it. The model reads only your messages in the chat above.

qwen2.5:7b on Ollama, temperature 0, 20 conversations, 25 Sep 2026. In 2 it chose AM or PM on its own when the guest hadn't said; in 1 it put "下周五" (next Friday) on a Tuesday. The rules asked instead, or got the date right.

Tests that gate every change

Every bug fix starts as a failing test. These synthetic conversations run in your browser against the code on this page, with a fixed clock (Fri 25 Sep 2026, 10:00). Each one also checks that no reply promises an email, text or call.
